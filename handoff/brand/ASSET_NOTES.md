# Original ShiftClarity assets
The mark and outlined wordmarks are original proposed product assets generated for this handoff. The parent company name/brand remains Supreme AI Ventures. Font files are not included. The wordmark contains outlines of the product name, not a reusable font. Runtime UI uses Inter when available and a system sans-serif fallback otherwise.

Use the inverse variants only on navy/dark surfaces. Keep minimum mark size 24 px and at least 1/4-mark clear space. See brand/UI specification for colors, spacing, typography and restrictions. The working name has not undergone trademark/domain clearance.
