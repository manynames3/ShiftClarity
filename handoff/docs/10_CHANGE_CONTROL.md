# 10 · Anti-drift and change control

## Frozen in v1
Name, category, tagline, parent endorsement, supplied mark, navy/teal/white token family, evidence-first layout, coverage semantics, input/rule/run lineage, decimal money, human approvals, no real data or live integrations in demo, and no revenue-recovery claims.

## Reversible implementation choices
Folder layout, accessible primitive library, exact supported stable dependency versions, and local demo state mechanism may change if they preserve the contract and are recorded. A new dependency must have a concrete job and a smaller alternative considered.

## Requires explicit approval
Changing product scope, adding clinical/home-care/payroll/credentialing features, replacing the brand direction, changing accounting or source precedence, reducing review controls, enabling real uploads or live connectors, cloud provisioning/spend, external messages, public Assist branding, pricing publication and production rollout.

## Change request template
CR-ID / date / requester / current behavior / proposed change / user value / impacted requirements and tests / data-security impact / design impact / costs / rollback / approval / implementation evidence.

## Stage status template
Checkpoint / authorized scope / changed files / acceptance IDs / tests actually run / browser screenshots / known issues / unresolved assumptions / next gate.

## Version and comparison
Record source kit version and hash manifest. Do not "fix" a fixture by changing expected values to match buggy output. A domain-change approval must update inputs, oracle, tests, docs and UI together. Design token changes require all reference screens to be reviewed, not one isolated page. Generated mood imagery never overrides the canonical reference.

## Acceptance is not a numeric aesthetic score
A screen is accepted when it matches the visual contract and the tested workflow is reliable at the named viewports. Do not claim "10/10 enterprise", "7-figure ready" or "better than incumbents" without a defined, measured basis.
